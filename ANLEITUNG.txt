RAUMSTEUERUNG SITZUNGSZIMMER 5 – EINRICHTUNG AUF DEM RAUM-PC
=============================================================

Inhalt des Pakets
-----------------
Raum5_Companion.companionconfig   Alle Companion-Buttons, Variablen, Verbindungen (OBS + RM-CR)
Raumsteuerung\                    Tablet-Seite + kleiner Webserver
  Raumsteuerung.exe               Das Programm (Symbol im Infobereich): startet die Dienste, Status, Einstellungen
  raumsteuerung.html              Die Tablet-Seite
  server.ps1                      Webserver (Port 8080)
  installieren.ps1                Richtet alles ein (als Administrator)
  deinstallieren.ps1              Entfernt Programm-Autostart und Firewall-Regeln
  teams-steuerung.ps1             Teams-Meeting vom Tablet bedienen (läuft im Hintergrund)

Raum5_OBS_Szenen_Backup.json      OBS-Szenen (Stand 05.10., Platzhalter statt echter Quellen)


1. Yamaha RM-CR
---------------
- RM-CR per Netzwerk mit dem Raum-PC verbinden.
- Feste IP-Adresse prüfen (RM Device Finder). Im Test war es 192.168.137.185.
- RM-CR per USB anschließen und in Windows als Standard-Audiogerät einstellen
  (Wiedergabe UND Aufnahme). Dann geht der Ton aus Teams über den Prozessor.


2. OBS Studio
-------------
- OBS installieren und starten.
- Szenensammlung -> Importieren -> Raum5_OBS_Szenen_Backup.json auswählen,
  dann unter Szenensammlung die importierte Sammlung anklicken.
- Werkzeuge -> WebSocket-Servereinstellungen:
  * "WebSocket-Server aktivieren" anhaken
  * Port 4455
  * "Authentifizierung aktivieren" anhaken, Passwort notieren
- Die farbigen Platzhalter (Präsentation, Redner, Publikum) später durch
  die echten Quellen ersetzen (Elgato HD60 X, NDI-Kameras). Position bleibt gleich.
- OBS immer über Datei -> Beenden schließen, sonst gehen Änderungen verloren.


3. Bitfocus Companion
---------------------
- Companion installieren (gleiche Version oder neuer, getestet mit 5.0.6).
- Web-Oberfläche öffnen: http://127.0.0.1:8000
- VORHER die laufende Konfiguration sichern: Import / Export -> Export (Datei aufheben).
- Import / Export -> Raum5_Companion.companionconfig importieren (alles übernehmen).
  Enthält alle Buttons für das Tablet (Seite 1 Steuerung, Seite 3 Kamera), die Variablen (r5_room, ...)
  und die Trigger. (Die Buttons der früheren Publikum-Automatik 3/1/x, 3/3/x sind noch drin, werden aber
  nicht mehr benutzt - die Publikum-Kamera ist fest auf den ganzen Raum gerichtet.)
- Connections -> obs -> Passwort von OBS eintragen (ist im Paket absichtlich leer).
- Connections -> rmcr -> IP-Adresse des RM-CR prüfen.
- Beide Verbindungen müssen grün sein.
- Settings: Companion beim Windows-Start automatisch starten lassen.
- Settings, Abschnitt HTTP: "HTTP API" muss eingeschaltet sein (Standard; Tablet und Automatik nutzen sie).


4. Webserver für das Tablet
---------------------------
- Ordner "Raumsteuerung" auf den Raum-PC kopieren.
- Rechtsklick auf installieren.ps1 -> "Mit PowerShell ausführen"
  (als Administrator; ggf. Admin-PowerShell öffnen und .\installieren.ps1 starten).
- Das Skript:
  * kopiert alles nach C:\Raumsteuerung
  * öffnet Port 8080 und 8000 in der Firewall (nur Domäne/Privat)
  * richtet Raumsteuerung.exe als Autostart bei jeder Anmeldung ein (alle Benutzer) und startet es
  * entfernt die früheren Aufgaben in der Aufgabenplanung (bis 22.10.2026)
  * zeigt am Ende die Adresse für das Tablet an, z. B. http://192.168.1.50:8080
- Raumsteuerung.exe (Symbol unten rechts im Infobereich, Punkt grün/gelb/rot) startet unsichtbar:
  Webserver (Port 8080) und Teams-Steuerung - und startet sie neu, falls sie abbrechen.
  Klick auf das Symbol: Status aller Teile, Tablet-Adresse, Einstellungen (RM-CR-IP, Bildschirm für
  "Präsentation zeigen", Teams-Link), Werkzeuge (Prüfen, Protokolle,
  Dienste neu starten). Neue Version: installieren.ps1 erneut ausführen. X schließt nur das Fenster.
  Beenden nur über Rechtsklick -> Beenden (dann gehen Tablet und Automatik nicht mehr).
- Die Seite findet Companion automatisch (gleicher PC, Port 8000).
- Wichtig: Der Raum-PC braucht eine feste IP-Adresse (oder DHCP-Reservierung).


5. Tablet
---------
- Tablet ins gleiche Netzwerk wie den Raum-PC bringen.
- Adresse aus Schritt 4 im Browser öffnen.

Android (Chrome):
- Menü (drei Punkte) -> "Zum Startbildschirm hinzufügen".
  Hinweis: Über http:// (ohne https) legt Chrome nur eine Verknüpfung an, keine echte App.
  Die Seite schaltet deshalb beim ersten Antippen selbst in den Vollbildmodus.
  Für Dauerbetrieb besser: App "Fully Kiosk Browser" (Startseite = Adresse aus Schritt 4,
  Kiosk-Modus an, Bildschirm immer an). Dann kann niemand die Seite verlassen.
- Einstellungen -> Sicherheit -> "App anheften" einschalten, App öffnen und anheften.
  So kann niemand die Seite aus Versehen verlassen.
- Display: Bildschirm-Timeout auf "nie" oder lange Zeit; Tablet am Ladegerät lassen.
- Anderer Companion-PC: einmalig  http://<Adresse>:8080/?companion=http://<IP>:8000  öffnen
  (wird im Tablet gespeichert).

iPad (Safari):
- Teilen -> "Zum Home-Bildschirm".
- Einstellungen -> Bedienungshilfen -> Geführter Zugriff einschalten,
  App öffnen und dreimal die Seitentaste drücken.
- Automatische Sperre: "Nie".


6. Test nach der Einrichtung
----------------------------
Zuerst C:\Raumsteuerung\pruefen.cmd doppelklicken: alles grün = Technik läuft, sonst steht dort, was zu tun ist.
[ ] Raum starten -> Virtual Cam läuft, Kachel "Nur im Raum"; "Teams-Meeting starten" -> nach ca. 15 s "Live in Teams"
[ ] Alle 5 Ansichten tippen -> OBS wechselt die Szene
[ ] Lautstärke + / - -> Lautsprecher werden leiser / lauter
[ ] Hilfe -> "Ton zurücksetzen" -> Ton an, mittlere Lautstärke
[ ] In OBS direkt Szene wechseln -> Tablet zeigt nach ca. 3 Sekunden die richtige Ansicht
[ ] Raum ausschalten -> Abfrage, danach Startbildschirm
[ ] Companion beenden -> Tablet zeigt Hinweis "Keine Verbindung zum Raum-PC",
    die Live-Kachel zeigt "Status unbekannt"
[ ] Kamera: Pfeil gedrückt halten -> Kamera fährt, loslassen -> Kamera stoppt
[ ] Raum am Stream Deck ausschalten -> Tablet springt auf den Startbildschirm
    (nur wenn Companion die Variable r5_room setzt, siehe unten)


Bei Problemen: IT-Service 2020


7. Publikum-Kamera (seit 22.10.2026 fest)
-----------------------------------------
Die Publikum-Kamera ist fest montiert, ohne Zoom, und zeigt immer den ganzen Raum. Es gibt keine
Steuerung und keine Automatik mehr (früher: mikro-automatik.ps1 schwenkte zum sprechenden Tischmikrofon).
Sie erscheint in den Ansichten "Diskussion" und "Alles im Blick". In OBS nur die Quelle einrichten.
"Prüfen" zeigt weiterhin die Mikrofon-Pegel des RM-CR (nützlich bei Tonproblemen).

                             Schalter an. Befehl je Button "MT00SW<Eingang><Ausgang>NT" + CRLF, Ausgang 00 = alle:
                               1/2/1 MT00SW0100NT (Eingang 1 = Raum-PC), 1/2/2 MT00SW0200NT (2 = Laptop),

9. Teams vom Tablet aus bedienen (Mikro, Bild, Verlassen)
-----------------------------------------------------------
Auf der Steuerung erscheinen unter dem Kopf große Teams-Knöpfe, sobald auf dem Raum-PC ein Teams-Meeting offen ist:
"Mikro an/aus", "Kamera an/aus", "Präsentation zeigen"; "Verlassen" klein oben im Kopf (erst nach zweitem Tippen).
So funktioniert es: teams-steuerung.ps1 liest und drückt die Buttons im Teams-Meetingfenster
über Windows UI Automation (wie ein Bildschirmleser). Keine Teams-API, kein Teams-Admin nötig.
  - Companion-Buttons 1/0/4 (Mikro), 1/0/5 (Bild), 1/0/6 (Verlassen) setzen r5_tcmd = mute/video/leave.
  - Das Skript meldet r5_t_in (Meeting offen), r5_t_mute (stumm), r5_t_video (Kamera an) zurück.
Einrichtung:
  a) Raumsteuerung.exe startet die Teams-Steuerung unsichtbar im angemeldeten Benutzerkonto (sie braucht den
     Desktop). Raum-PC: automatische Anmeldung des Raum-Kontos einrichten, sonst läuft sie erst nach Anmeldung.
     Neustart: Raumsteuerung -> Werkzeuge -> Dienste neu starten.
  b) Nach installieren.ps1 läuft sie sofort (kein Ab-/Anmelden nötig).
  c) Test: Teams-Meeting starten -> Tablet zeigt die Leiste. "Mikro" tippen -> Teams schaltet stumm.
     Ohne Tablet: C:\Raumsteuerung\teams-steuerung.ps1 -Status   bzw.  -Befehl mute
  d) Protokoll: C:\Raumsteuerung\teams-steuerung.log
Meeting des Raums per Knopf starten ("Teams-Meeting starten" oben am Tablet; "Raum starten" schaltet nur den Raum ein):
  e) Einmal ein festes Meeting des Raumkontos anlegen (Serie ohne Enddatum oder dauerhafter
     Besprechungslink) und den Link in C:\Raumsteuerung\teams-link.txt speichern (eine Zeile).
     Die Datei liegt nur auf dem Raum-PC, nicht im Repository. installieren.ps1 überschreibt sie nicht.
  f) In den Besprechungsoptionen: "Wer kann den Wartebereich umgehen" = "Alle" (sonst warten
     Online-Teilnehmer, bis jemand im Raum sie zulässt).
  g) Ablauf: Companion 1/0/7 setzt r5_tcmd = join -> teams-steuerung.ps1 öffnet den Link in Teams,
     schaltet Kamera + Mikro ein, drückt "Jetzt teilnehmen" (ca. 15 s). Das Meetingfenster bleibt offen.
     Fortschritt/Fehler in r5_t_status, das Tablet zeigt "Teams-Meeting startet …" bzw. einen Hinweis.
     "Raum ausschalten" (1/0/2) verlässt auch das Meeting.
  h) Teams läuft auf einem eigenen Monitor am Sprecherplatz (zusammen mit OBS), dort sieht man Teilnehmer
     und Chat und kann auch direkt klicken. Die Displays zeigen nur die Präsentation. Ist das Meetingfenster
     minimiert, holt das Skript es vor dem Drücken wieder hervor (minimiert reagiert Teams erst nach Sekunden).
  i) Das Tablet schickt Zielzustände (mic_on/mic_off/video_on/video_off), das Skript drückt nur, wenn Teams
     anders steht. Die Stream-Deck-Tasten 1/0/4 und 1/0/5 schalten weiterhin um.
Teams-Bild: Präsentation geteilt + Personen über die Kamera (Standard; seit 22.10.2026 ohne OBS-Projektor):
  j) Zwei Kanäle wie bei Teams Rooms:
     - Inhalt: "Präsentation zeigen" lässt Teams einen ECHTEN Bildschirm teilen - den, auf dem die Präsentation
       läuft ("Nur Inhalt", "Sound einschließen"). Text und Folien kommen scharf und groß an.
     - Personen: Teams-Kamera = OBS Virtuelle Kamera (Programm: Nur Redner / Diskussion / Pausenbild), flüssig.
     Das Tablet blendet im Modus "teilen" die Ansichten "Alles im Blick"/"Folien groß" aus (r5_t_mode); stehen sie
     beim Teilen noch auf dem Programm, schaltet das Skript auf "Nur Redner".
  k) Welcher Bildschirm: mikro-automatik.json "teilenBildschirm" = Nummer wie in Windows (Einstellungen ->
     Anzeige, z. B. "2") oder Teil des Monitornamens. Ohne Eintrag: der Hauptbildschirm. pruefen.cmd listet
     alle Bildschirme mit Nummer und zeigt, welcher geteilt wird. Ist der eingetragene nicht da (Monitor aus),
     teilt das Skript nichts und das Tablet sagt "Präsentation nicht geteilt - in Teams von Hand teilen".
     Einfacher: Raumsteuerung -> Einstellungen -> Bildschirme. Dort "Präsentation zeigen" und "Teams-Fenster"
     wählen; "Nummern zeigen" blendet auf jedem Bildschirm 4 s lang Nummer und Aufgabe ein.
     Teams-Fenster ("teamsBildschirm"): Nummer, Teil des Monitornamens oder "aus" (nie verschieben). Ohne Eintrag
     der erste Neben-Bildschirm, der nicht geteilt wird. Das Skript legt große Teams-Fenster alle 5 s dorthin,
     auch vom Präsentations-Bildschirm weg (außer während des Teilens).
  l) "Teams-Meeting starten" tritt nur mit Kamera bei (ca. 20 s), Kamera-Szene immer "Nur Redner".
     Die Präsentation teilt erst der Knopf "Präsentation zeigen" (r5_tcmd share_on/share_off,
     Zustand r5_t_share, ca. 10 s); "Präsentation beenden" stoppt das Teilen. "Kamera an/aus" = Teams-Kamera.
     "Verlassen"/"Raum ausschalten" beenden zuerst das Teilen (sonst fragt Teams nach).
  m) Teams geteilt sieht alles, was auf diesem Bildschirm ist (auch Benachrichtigungen, andere Fenster) - die
     Präsentation dort im Vollbild zeigen. Teams selbst liegt auf dem Sprecherplatz-Monitor (teamsBildschirm).
  n) Zurück zur Virtuellen Kamera ohne Teilen: in C:\Raumsteuerung\mikro-automatik.json  "teamsBild": "kamera"
     eintragen und Raumsteuerung -> Werkzeuge -> Dienste neu starten. Ton aus beim Teilen: "teilenTon": false.
  o) Die Bildschirme heißen in der Teams-Liste alle gleich; das Skript probiert zuerst den zuletzt richtigen
     Eintrag (teilen-eintrag.txt) und prüft an der Lage der Teams-Leiste "Freigabesteuerungsleiste", ob der
     richtige Bildschirm geteilt wird.
Grenzen: Teams kennt keinen auslesbaren Zustand für "Hand heben" - deshalb keine Hand-Taste.
Organisator übergeben, Wartebereich, andere stummschalten: nur in Teams selbst.
Nach großen Teams-Updates kann eine Button-Kennung wechseln (microphone-button, video-button,
hangup-button) - dann in teams-steuerung.ps1 ($IDS) anpassen.

10. Raum-PC Grundeinrichtung (einmalig) - damit Nutzer nichts starten müssen
-------------------------------------------------------------------------------
Ziel: Nach dem Einschalten des PCs läuft alles von selbst, am Tablet nur "Raum starten".
Startet automatisch:
  - Raumsteuerung.exe               bei Anmeldung (installieren.ps1); startet Webserver,
                                    Teams-Steuerung + OBS-Wächter (startet OBS im Infobereich
                                    (--minimize-to-tray --disable-shutdown-check) und nach einem Absturz neu,
                                    bei eingeschaltetem Raum gleich mit Virtual Camera
  - Companion                       Companion-Fenster: "Run at login" anhaken
  - Teams                           Teams -> Einstellungen -> Allgemein -> "Teams automatisch starten"
  - Virtual Camera                  schaltet "Raum starten" (Companion 1/0/1) ein, "Raum ausschalten" aus
Windows einmal einstellen:
  [ ] Automatische Anmeldung des Raumkontos (sonst startet nach dem Einschalten nichts von "bei Anmeldung")
  [ ] Energieoptionen: Bildschirm aus / Energiesparmodus = "Nie"; Bildschirmschoner aus; Sperre bei Inaktivität aus
  [ ] Benachrichtigungen von Windows und Teams aus (Fokus / "Nicht stören"), sonst erscheinen sie auf den Displays
  [ ] Windows Update: Nutzungszeit z. B. 7-20 Uhr, Neustarts nur außerhalb
  [ ] Teams: Geräte = OBS Virtual Camera / Yamaha RM-CR; "Mein Video spiegeln" aus
  [ ] Bildschirme festlegen: Raumsteuerung -> Einstellungen -> Bildschirme ("Präsentation zeigen", "Teams-Fenster";
      "Nummern zeigen" zum Zuordnen), danach pruefen.cmd: Zeilen "Praesentation teilen" und "Teams-Fenster" grün
Wartung: OBS bewusst schließen (z. B. zum Bearbeiten) -> der Wächter startet es nach spätestens 30 s neu.
Dafür vorher Raumsteuerung beenden (Rechtsklick auf das Symbol -> Beenden), danach wieder starten.
